# REF-016 — Add deterministic offline eval mode

## Goal
Enable fast, deterministic local development runs without network/Claude calls, while keeping real integration mode available.

## Blockers / Dependencies
- Merge after: REF-001 (harness correctness).
- May require minimal seams if the hook hardcodes the `claude` binary in a non-PATH-respecting way.

## Files
- `test/evals/run-evals.sh`
- `test/evals/` (mock `claude` binary/script + fixtures)
- `hooks/claude-judge-continuation.sh` (only if needed to allow `CLAUDE_BIN` override; prefer not)

## Work (Tasks)
1. Add a mock `claude` executable under `test/evals/` that returns deterministic JSON matching the hook’s expected schema.
2. Add a harness flag/env var (e.g., `EVAL_OFFLINE=1`) that prepends the mock directory to `PATH`.
3. Ensure offline mode is opt-in and clearly logged (stderr).
4. Keep “real mode” as the default for final validation.

## Acceptance Criteria
- [ ] At least one scenario runs deterministically with `EVAL_OFFLINE=1` and no network.
- [ ] Default behavior remains unchanged (real Claude runner).
- [ ] Offline mode is opt-in and documented in the eval output.

## Proving Commands
- Real: `./test/evals/run-evals.sh`
- Offline: `EVAL_OFFLINE=1 ./test/evals/run-evals.sh`
