<task type="auto">
  <name>Task 1: Integrate stall detection into main hook flow</name>
  <files>hooks/claude-judge-continuation.sh</files>
  <action>
Add stall detection between heuristic check and judge call:

1. After heuristic check (around line where heuristic_should_stop is called):
   - Compute context hash: `CONTEXT_HASH=$(compute_context_hash "$RECENT_CONTEXT")`
   - Read previous context hash from throttle file
   - Detect stall signals: `STALL_SIGNAL=$(detect_stall "$CONTEXT_HASH" "$DECISION_LOG")`
   - Calculate stall risk: `STALL_RISK=$(calculate_stall_risk ...)`

2. Adjust decision thresholds based on stall risk:
   - If STALL_RISK > 70 (HIGH):
     - If judge recommends continue but confidence < 0.75 → force stop
     - Log: "stall_override: high risk forced conservative decision"
   - If STALL_RISK 40-70 (MODERATE):
     - Raise confidence threshold from 0.5 to 0.65 for continue decisions
     - Log: "stall_warning: moderate risk, stricter threshold"

3. Update throttle record with context hash on continuation:
   - Call `throttle_write` with 4th parameter `$CONTEXT_HASH`

4. Pass stall metadata to persist_decision:
   - Include `$STALL_RISK` and `$CONTEXT_HASH` in decision output

5. Update path logging to include stall info:
   - Format: `permission | heuristic | stall:45 | judge`
   - Or: `permission | heuristic | stall:85(override) | -`

**CRITICAL:** Stall detection should NOT block heuristic-approved decisions. Heuristics are deterministic and trusted. Stall detection only affects judge-based decisions.
