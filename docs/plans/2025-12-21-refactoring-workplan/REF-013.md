# REF-013 — Add snapshot tests for prompt + schema

## Goal
Make prompt/schema changes reviewable and catch accidental drift before it reaches the LLM.

## Blockers / Dependencies
- Merge after: REF-001 (trustworthy harness).
- Optional alignment with: REF-003 (stable output).

## Files
- `hooks/claude-judge-continuation.sh` (prompt/schema extraction point)
- `test/` (new snapshot fixture + script)

## Work (Tasks)
1. Create a tiny script that prints the generated prompt (and/or schema) for a fixed fixture transcript.
2. Store a snapshot under `test/` (deterministic file content).
3. Fail the snapshot check if the generated prompt/schema differs.

## Acceptance Criteria
- [ ] Snapshot check fails on unexpected prompt/schema edits.
- [ ] Snapshot update workflow is explicit (update fixture + run evals).
- [ ] No new runtime dependency is required by users installing the plugin.

## Proving Commands
- `./test/evals/run-evals.sh`
- `./test/<new-snapshot-script>.sh`
