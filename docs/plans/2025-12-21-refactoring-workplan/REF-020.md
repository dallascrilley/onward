# REF-020 — Add optional structured debug logging

## Goal
Make troubleshooting possible without breaking the JSON stdout contract.

## Blockers / Dependencies
- Merge after: REF-001

## Files
- `hooks/claude-judge-continuation.sh`

## Work (Tasks)
1. Add an env-guarded debug mode (e.g., `REDBULL_DEBUG=true`).
2. Emit structured debug logs to **stderr only** (include timestamps, key decisions, throttle state).
3. Ensure debug mode never leaks transcripts or secrets by default (log metadata, not content).

## Acceptance Criteria
- [ ] Default behavior is unchanged (no debug output).
- [ ] Debug output is only on stderr and cannot corrupt stdout JSON.
- [ ] Eval suite passes with debug disabled (and optionally with debug enabled).

## Proving Commands
- `./test/evals/run-evals.sh`
- `REDBULL_DEBUG=true ./test/evals/run-evals.sh`
