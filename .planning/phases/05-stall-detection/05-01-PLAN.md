<task type="auto">
  <name>Task 1: Add stall detection functions to judge.sh</name>
  <files>hooks/lib/judge.sh</files>
  <action>
Add two new functions at the end of judge.sh (after existing functions):

1. `detect_stall()` - Analyze decision history for stall signals
   - Parameters: `$current_context_hash`, `$decision_log_file`
   - Read last 5 decisions from log with `tail -n 5`
   - Check for context_hash unchanged across entries
   - Check for confidence trend declining (3+ decisions with decreasing values)
   - Check for same decision_category repeated 3+ times
   - Output one of: "context_unchanged", "confidence_declining", "same_category_repeated", or return 1 (no stall)

2. `calculate_stall_risk()` - Compute risk score 0-100
   - Parameters: `$context_unchanged` (0/1), `$confidence_declining` (true/false), `$category_repeat_count`, `$throttle_count`
   - Point allocation:
     - Context unchanged: 30 points
     - Confidence declining: 20 points
     - Category repeated 3+: 20 points
     - Throttle count: 15 points per continuation
   - Cap at 100, echo score

**IMPORTANT:** Use SHA256 for context hashing (sha256sum). Normalize context before hashing by extracting only the last assistant message content to avoid false progress from metadata/timestamp changes.
  </action>
