## Tasks

<task type="auto" id="1">
  <name>Add permission language detection functions to judge.sh</name>
  <files>hooks/lib/judge.sh</files>
  <action>
    Add two new functions at end of judge.sh:
    1. detect_permission_language() - extracts last assistant message, checks for:
       - Permission-seeking patterns: "should i continue", "shall i proceed", "is it (ok|alright|fine) if i", "ready to proceed"
       - Explicit choice patterns: "which.*prefer", "choose", "does this.*(look|seem|sound).*(good|ok|correct)"
       - Optional work patterns: "(want me to|should i also).*(optional|nice.?to.?have|if you want)"
    2. permission_language_decision() - maps pattern type to decision (block/approve/empty)
  </action>
  <verify>source hooks/lib/judge.sh; echo '[{"role":"assistant","content":"Should I continue implementing?"}]' | detect_permission_language returns "permission_seeking"</verify>
  <done>Functions added and sourced without errors</done>
</task>

<task type="auto" id="2">
  <name>Integrate prefilter into main hook</name>
  <files>hooks/claude-judge-continuation.sh</files>
  <action>
    Add permission language check between ignore patterns check (line ~147) and judge call (line ~149):
    - Call detect_permission_language with RECENT_CONTEXT
    - If pattern detected, call permission_language_decision
    - If decision is block/approve, emit_decision and exit early
    - Add debug_log for permission_language path
    - If no pattern or empty decision, fall through to judge
  </action>
  <verify>Run hook with mock permission-seeking transcript; verify it exits before judge call</verify>
  <done>Prefilter integrated; permission patterns bypass judge</done>
</task>
