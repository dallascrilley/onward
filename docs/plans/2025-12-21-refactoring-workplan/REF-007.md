# REF-007 — Centralize and parameterize script paths

## Goal
Prevent path drift by making the hook path a single source of truth across tests and docs (without changing hook behavior).

## Blockers / Dependencies
- Coordinate with: REF-001 (must agree on the canonical hook entrypoint path).

## Files
- `test/evals/run-evals.sh`
- `hooks/hooks.json`
- `hooks/run-hook.cmd`
- `CLAUDE.md`
- `RELENG.md`
- `README.md` (only if it references old paths)

## Work (Tasks)
1. Establish the canonical hook entrypoint path used by tests and docs.
2. Prefer `${CLAUDE_PLUGIN_ROOT}` in hook configuration for portability.
3. Remove/replace lingering `scripts/` references that imply a different layout (coordinate with REF-019).

## Acceptance Criteria
- [ ] Tests and docs reference the same hook entrypoint path.
- [ ] Hook configuration remains portable across install locations.
- [ ] `./test/evals/run-evals.sh` still runs.

## Proving Commands
- `./test/evals/run-evals.sh`
- `rg -n \"scripts/\" -S .`
