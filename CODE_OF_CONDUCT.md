# Code of Conduct

## The short version

Be decent. Assume good faith. Critique the code, not the person.

## Standards

Behavior that keeps this project worth contributing to:

- Being respectful of differing opinions and experience levels
- Giving and accepting constructive feedback
- Taking responsibility for mistakes and learning from them
- Focusing on what is best for the project

Behavior that does not:

- Sexualized language or imagery, or unwelcome sexual attention
- Trolling, insults, derogatory comments, and personal or political attacks
- Public or private harassment
- Publishing others' private information without explicit permission

## Enforcement

Report unacceptable behavior through [GitHub Security Advisories](https://github.com/dallascrilley/onward/security/advisories/new) or by opening an issue asking for a private contact address. Reports are handled confidentially. I may remove comments, close contributions, or block accounts that violate these standards.
