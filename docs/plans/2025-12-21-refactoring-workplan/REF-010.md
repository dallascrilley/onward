# REF-010 — Improve transcript extraction robustness

## Goal
Handle NDJSON edge cases safely (missing file, empty lines, invalid JSON lines) without changing “normal” behavior.

## Blockers / Dependencies
- Merge after: REF-001
- Recommended after: REF-003 (centralized error/decision emission).

## Files
- `hooks/claude-judge-continuation.sh`

## Work (Tasks)
1. Add guards for missing/unreadable transcript files (fail closed: approve stop with reason).
2. Make NDJSON parsing tolerant of empty/invalid lines (skip invalid lines; keep last N valid entries).
3. Ensure bounded behavior (never read unbounded transcript content).

## Acceptance Criteria
- [ ] Missing transcript file does not crash the hook.
- [ ] Invalid NDJSON lines do not crash the hook.
- [ ] Behavior on valid transcripts remains consistent (eval parity).

## Proving Commands
- `./test/evals/run-evals.sh`
